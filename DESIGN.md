# EJII Design System — Obsidian Horizon Glass & Precision Telemetry

**1. Aesthetic Direction (`Product & Data Dashboard Mode`):** Eldar Jamiyev Infrastructure Intelligence (EJII) embodies the **"Obsidian Horizon Glass & Precision Telemetry"** paradigm—an intentional, high-contrast dark infrastructure workstation aesthetic engineered for sovereign network operations and L1–L7 wire-level diagnostics. Surfaces are crafted with layered physical depth: a full-viewport obsidian-midnight atmospheric vista (`#050811`) with warm crimson-amber horizon refraction and cool cyber-twilight depth illuminates a suspended, ultra-translucent frosted glass authentication and control card (`rgba(12, 16, 28, 0.38)`, `backdrop-filter: blur(26px) saturate(185%)`, `1px solid rgba(255, 255, 255, 0.28)` hairline border, and `inset 0 1px 0 rgba(255, 255, 255, 0.35)` top specular edge highlight). Every layout decision prioritizes optical clarity, scannable hierarchy, and zero-scroll viewport equilibrium without gimmicky clutter.

**2. Typography System (`/typeset`):** The typographic hierarchy pairs **Bricolage Grotesque** (`800`–`900` extra-bold display weight, tight `-0.03em` tracking, `1.12` line-height) for authoritative display headings with **DM Sans** (`400`/`500`/`600` weights) for crisp, high-legibility interface prose and **JetBrains Mono** (`400`/`500`/`700` weights with `font-variant-numeric: tabular-nums`) for live network telemetry chips, IP/CIDR readouts, cryptographic status capsules, and RBAC metadata. Generic and overused typefaces—specifically `Inter`, `Roboto`, `Arial`, `Open Sans`, `Lato`, `Space Grotesk`, default system sans fallbacks as primary fonts, and italic-serif display heroes—are strictly prohibited.

**3. Color, Glass & Motion Tokens (`/colorize` & `/animate`):** Root CSS custom properties standardize the palette and choreography across all stylesheets: `--ejii-canvas-obsidian: #050811`, `--ejii-horizon-crimson: #e11d48`, `--ejii-horizon-rose: #be185d`, `--ejii-twilight-amber: #f59e0b`, `--ejii-cyber-cyan: #06b6d4`, `--ejii-deep-indigo: #1e1b4b`, `--ejii-glass-surface: rgba(12, 16, 28, 0.38)`, `--ejii-glass-border: rgba(255, 255, 255, 0.28)`, and `--ejii-glass-specular: inset 0 1px 0 rgba(255, 255, 255, 0.35)`. Motion obeys a strict **2-Moment Budget**: **Moment 1 (Orchestrated Page Load)** pairs a serene 20-second `@keyframes float` horizon aurora drift with a staggered entrance sequence (`.fade-in` with `.delay-1` through `.delay-6` using `cubic-bezier(0.22, 1, 0.36, 1)`); **Moment 2 (Primary User Action)** delivers a crisp `200ms` focus border illumination (`rgba(255, 255, 255, 0.9)` + outer halo) on pill inputs, interactive cursor-tracking border sheen (`--mouse-x`, `--mouse-y`), and a `-2px` tactile hover lift on the solid white primary pill CTA (`#FFFFFF` surface, `#060913` ink), while honoring `@media (prefers-reduced-motion: reduce)`.
