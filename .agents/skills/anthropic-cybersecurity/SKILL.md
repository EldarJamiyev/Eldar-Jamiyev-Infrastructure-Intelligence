# Anthropic Cybersecurity Skills

A standardized cybersecurity framework for autonomous AI agents covering 818 security controls across 6 industry standards:

## Framework Alignment

| Framework | Domain | Key Coverage |
|---|---|---|
| **MITRE ATT&CK** | Adversarial Tactics & Techniques | Initial Access, Execution, Persistence, Privilege Escalation, Defense Evasion, Credential Access, Lateral Movement |
| **NIST CSF 2.0** | Posture & Governance | Identify, Protect, Detect, Respond, Recover, Govern |
| **MITRE ATLAS** | Adversarial ML Threats | Prompt Injection, Data Poisoning, Model Evasion, Model Extraction |
| **MITRE D3FEND** | Countermeasures | Model Hardening, Access Filtering, Credential Hardening, Network Isolation |
| **NIST AI RMF** | AI Risk Management | Trustworthy AI, Bias & Fairness, Robustness, System Monitoring |
| **MITRE F3** | Financial Fraud | Transaction Laundering, Identity Theft, Synthetic Accounts |

## Operational Procedures

1. **Reconnaissance & Asset Discovery:**
   - Map attack surface, open ports, exposed APIs, and dependency vulnerabilities (SCA).
2. **Threat Modeling & Gap Analysis:**
   - Map identified risks to MITRE ATT&CK IDs and NIST CSF subcategories.
3. **Automated Defensive Verification:**
   - Perform static code security audits (SAST) and dynamic scans (DAST).
   - Enforce least privilege, secret zero exposure, and cryptographic sanity.
