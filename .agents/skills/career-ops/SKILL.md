# Career-Ops — Profile Ingestion & Competency Mapping

Career-Ops analyzes an engineer's technical background, certification level (e.g. Network+, CCNA, CCNP, CKA), and operational familiarity to dynamically calibrate educational content, diagnostic explanations, and automation clearance.

---

## 🎓 Competency Tier Calibration

```
[ Tier 1: Junior NOC Operator ]
  ├── Detailed explanations of OSI layers and TCP flags
  ├── Confirmation modals for all script executions
  └── Guided step-by-step diagnostic workflows

[ Tier 2: Mid-Level SRE / Systems Engineer ]
  ├── Concise CLI summaries with key metric deltas
  ├── Tier 2 automation permissions (cache flushes, service restarts)
  └── Deep root-cause causal DAGs

[ Tier 3: Principal Network Architect ]
  ├── Raw BPF filter expressions and hex byte offsets
  ├── Direct execution clearance with Lyapunov safety overrides
  └── Architectural drift and capacity planning models
```
